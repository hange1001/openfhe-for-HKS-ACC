## 1. 环与多项式

| 符号 | 含义 | 当前值 |
|---|---|---|
| `N` | 环维数（多项式次数） | **4096** = 2^12 |
| `R = Z[X]/(X^N+1)` | 多项式环 | |
| **tower / limb** | 一个 `Z_{q_i}[X]/(X^N+1)` 上的多项式，含 `N` 个系数 | 32 KB |
| `n` | 系数下标，`n ∈ [0, N)` | |
| `‖·‖` | 中心剩余绝对值（系数取 `(−q/2, q/2]`） | |

> 全文用**中心剩余**约定。误差界因此形如 `m/2` 而非 `m−1`（非中心口径），紧一倍。

## 2. 模数体系

| 符号 | 含义 | 当前值 |
|---|---|---|
| `q_i` | Q 侧单个素数 | ~2^60 |
| `Q` | **全**模数链 `∏q_i`，keygen 时定死 | |
| `Q_ℓ` | **当前层**模数 `= q_0···q_{ℓ−1}` | |
| `ℓ` = `sizeQl` | 当前层 tower 数 | **3** |
| `L` | 最大乘法层数 | |
| `p_j` | P 侧单个素数（辅助/特殊素数） | ~2^60 |
| `P` | 辅助模数 `= ∏_{j} p_j` | |
| `K` = `sizeP` | P 的素数个数 | **2** |
| `ℓ + K` = `sizeQlP` | 全基 tower 数 | **5** |

> **存储基 ≠ 运算基**：`evk` 存在 `Q·P` 上（全 `L+1+K` 个 tower），
> key switch 运算在 `Q_ℓ·P` 上（`ℓ+K` 个）。
> 代码痕迹：`keyswitch-hybrid.cpp:647` 的 `idx = sizeQ` 偏移（不是 `sizeQl`）。

## 3. digit 分解

| 符号 | 含义 | 当前值 |
|---|---|---|
| `dnum` = `numPartQl` | digit 个数 | **2** |
| `α` = `numPerPartQ` | 每 digit 的 tower 数（标称，`= ⌈ℓ/dnum⌉`） | **2** |
| `α_j` | 第 `j` 个 digit **实际** tower 数（末位可残缺） | α₀=2, α₁=1 |
| `Q_j` | digit `j` 的模数积 `= ∏_{i ∈ digit j} q_i` | |
| **`d_j = c1 mod Q_j`** | **digit `j` 承载的整数**（⚠️ 不是 `c1` 本身） | `‖d_j‖ ≤ Q_j/2` |
| `C_j` | digit `j` 的 BConv 目标基 `= (Q_ℓ \ Q_j) ∪ P` | |
| `\|C_j\| = ℓ + K − α_j` | 目标基大小 | **3 / 4** |

> **残缺 digit**：`ℓ` 除不尽 `α` 时末位 digit 短。当前 `ℓ=3, α=2` → `α₁=1`，
> 于是 `\|C_1\|=4 ≠ \|C_0\|=3`。这是小参数产物；参数上推时优先选能整除的 `(ℓ, dnum)`。

## 4. CRT 构件（两个粒度，同一结构）

| 粒度 | 符号 | 含义 | OpenFHE 名字 |
|---|---|---|---|
| **单素数** | `Q̂_i = Q/q_i` | 补模数 | — |
| | `Q̂_i^{-1} mod q_i` | 归一系数 | `QHatInvModq` / `PartQlHatInvModq` |
| | `Q̂_i mod p_j` | BConv 权重 | `QHatModp` / `PartQlHatModp` |
| | `E_i = (Q̂_i^{-1} mod q_i)·Q̂_i` | 基向量（正交幂等元） | — |
| **digit** | `Q̂_j = Q_ℓ/Q_j` | 补模数 | — |
| | `E_j` | digit 级基向量（`Q_j` 上 ≡1，其余 Q tower 上 ≡0） | 体现为 evk 的 tower 结构 |

> **关键恒等式**（全文用了三次以上）：`模数 × 补模数 = 总模数`
> 单素数层 `q_i·Q̂_i = Q` → 保证"先 mod q_i"的约减合法
> digit 层 `Q_j·Q̂_j = Q_ℓ` → 让 BConv 误差在信号项中被歼灭

## 5. 密钥与密文

| 符号 | 含义 |
|---|---|
| `s` | **新密钥**（key switch 的目标） |
| `s′` | **旧密钥**（源） |
| `c = (c_0, c_1)` | 输入密文，`c_0 + c_1·s′ ≡ m + e (mod Q_ℓ)` |
| `evk_j = (b_j, a_j)` | 第 `j` 份 evk，满足 `b_j + a_j·s = P·s′·E_j + ε_j` |
| `ε_j` | evk 的加密误差 |
| `B` | 误差界，`‖ε_j‖ ≤ B`（几比特） |

> `ε` 是**噪声的唯一源头**——RLWE 的安全性要求，不可去除。

## 6. ModUp 中间量

| 符号 | 含义 | 界 |
|---|---|---|
| `x_i = (c[i]·QHatInv_i) mod q_i` | BConv 的共享量（跨输出 `j` 复用） | `< q_i` |
| `ĉ_j` | digit `j` 扩展到全基后的多项式 | |
| `u` (或 `u_j`) | **ModUp** BConv 的溢出量 | `‖u‖ ≤ α/2` |
| `c̃ = (c̃_0, c̃_1)` | P4 的输出，在 `Q_ℓ·P` 上 | |
| `η = Σ_j ĉ_j·ε_j` | KS 累积噪声（**只在解密组合里存在**） | `≈ dnum·(1+α)·Q_j·B/2` |

## 7. ModDown 中间量

| 符号 | 含义 | 界 |
|---|---|---|
| `g` | 想要的结果（`= c1·s′`） | |
| **`ρ = c̃ mod P`** | c̃ 对 P 的中心剩余（⚠️ 曾误记为 `s`） | `‖ρ‖ ≤ P/2` |
| `ρ̂ = ρ + w·P` | BConv 给出的近似 | |
| `w` | **ModDown** BConv 的溢出量 | `‖w‖ ≤ K/2` |
| `P^{-1} mod q_i` | 预计算常数 | `GetPInvModq()` |
| `out` | ModDown 输出 `= round(c̃/P) − w` | |

### 9.1 AI（算术强度）的三条口径规定（2026-08-13，源：L1_优化术语对表.md §3.3）

任何写下的 AI 数字必须同时声明三件事，缺一即为无口径数字（traceability 规则适用）：

1. **分子**：op 的计法。**本项目统一：1 次模乘加（MAC）计 1 op**；纯模加/减不计。
   与文献 ops 口径（乘、加分开数）对比时 ×2。
   ⚠️ 历史遗留：`BConv 0.23 MAC/B` 与 `B0 0.32 ops/byte` 分子不同源，引用前须先换算归一。
2. **分母**：字节跨过的边界写进变量名，不同边界不可同屋顶比较：

   | 变量名 | 边界 | 现役数字 |
   |---|---|---|
   | `AI_pcie` | host ↔ 加速器 | B0/B1/B4 = 0.32 / 0.89 / 2.1 |
   | `AI_hbm` | 加速器内 HBM ↔ 片上 | （空缺，step 1.3 补） |
   | `AI_axi` | kernel AXI 端口 | BConv 0.23 MAC/B |

3. **evk**：声明是否含 evk 流量。CiFlow 表 II 【含】；本项目当前【不含】。
   与文献对比前必须换算并标注。

## 10. 一页速查

```
参数：  N=4096   ℓ=3   K=2   dnum=2   α=2   (α₀=2, α₁=1)
形状：  (N×ℓ) → dnum×(N×α_j) → dnum×(N×(ℓ+K−α_j)) → dnum×(N×(ℓ+K)) → 2×(N×(ℓ+K)) → 2×(N×ℓ)
误差：  ModUp BConv ‖u‖≤α/2      ModDown BConv ‖w‖≤K/2
噪声：  唯一源头 ε（evk）；BConv 只【放大】不【产生】，放大约 (1+α) 倍
约束：  P ≳ α·Q_j·B   →   K = α (+1)
恒等：  q_i·Q̂_i = Q        Q_j·Q̂_j = Q_ℓ        （同一结构，两个粒度）
```
